## Lessons that cost real time today, do not relearn them

- `node --check` exits 0 without parsing any `.js` file that contains
  `import`. Force module parsing (copy to `.mjs`) or the sweep lies.
- Automated text sweeps must never touch regex character classes, CSV/test
  fixtures, string literals compared against stored user data, or the exempt
  standalone placeholders. The suites catch all of it; run every app's tests
  before any deploy.
- Search Console: submit the full sitemap URL, not the relative shortcut;
  the 2020-era property resolves shortcuts against www.
- The seating chart's ", ," fixture damage and rock-stops' land-type
  migration are examples of the sweep class; grep the sweep commit, not just
