## Lessons that cost real time today

- **The emulator does not enforce Firestore's 500-write batch ceiling.** The
  end-to-end test for the Clear checked fix passes against the broken code too.
  It was run both ways to find that out, and the guarantee is asserted off the
  source instead. Do not trust a green emulator test about a platform limit.
- **A guard that cries wolf gets deleted.** The CSS placement guard learned its
  allowlist from the first app alphabetically, which is astravault, which is
  build output from another repo and has never carried the studio base. Empty
  reference, twenty four false alarms, every day, for nobody.
- **Two auditors are worth far more than one, and not because they agree.**
  Every disagreement was a place where one of them had done shallow work, and
  the code always said which. Keep doing this.
- **Neither auditor could find the panel bug and both said so honestly.** The
  answer was in the box model, not the code: a hidden radio absolutely
  positioned inside a static label belongs to the nearest positioned ancestor,
  which was the dialog. When a UI bug will not show up in the source, measure
  the boxes.
- **jsdom ignores assignment to `localStorage.setItem`.** Break
  `Storage.prototype.setItem` instead or the quota test lies.
- `firebase.json` at the repo root declares hosting only. Rules deploy from
  `apps/signup-sheets/`, which has its own config.
