# Wedding Day Timeline

The day-of schedule — hair, first look, ceremony, toasts, last dance — sorted
automatically, then printed as an elegant serif page for the planner, the DJ,
the photographer, and whoever is keeping grandpa on schedule. Same audience as
our Seating Chart, earlier in the same week. Forgiving time parsing ("2pm",
"2:30 PM", "14:30" — unit-tested), URL-shareable, localStorage-persistent.
A free tool by Sky Wolf Studio.

`CONFIG.tipUrl` in `app.js` for the tip jar. Test: `node test/helpers.test.mjs`.
