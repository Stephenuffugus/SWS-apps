# Wheel Picker

A fair spinning wheel for picking names, chores, raffle winners, and "who goes
first." Teachers use these daily; the popular ones are plastered with ads and
autoplay video. Ours: no ads ever, and the whole wheel — names and settings —
lives inside the URL, so a bookmarked class list works forever. A free tool by
Sky Wolf Studio.

Remove-winner mode for raffles and cold-calling (with one-tap restore),
smooth ease-out spins, adjacent-slice colors guaranteed distinct (tested,
including the wrap-around), unicode-safe link state. `CONFIG.tipUrl` in
`app.js` for the tip jar. Test: `node test/helpers.test.mjs`
