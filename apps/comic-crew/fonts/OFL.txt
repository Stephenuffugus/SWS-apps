COMIC CREW: FONT LICENCES
=======================

Comic Crew ships two typefaces. Both are licensed under the SIL Open Font
License, Version 1.1. The full licence text for each family is reproduced
below, in full, after that family's own copyright notice, as OFL clause 2
requires. This file travels with the font binaries in this directory and
must not be separated from them.

FILES SHIPPED
-------------

  bangers-latin.woff2         Bangers, weight 400, latin subset
                              23,528 bytes
                              Display face: the logo, panel lettering,
                              sound effects.

  shantellsans-latin.woff2    Shantell Sans, variable weight 300 to 800,
                              roman, latin subset
                              79,292 bytes
                              Hand face: balloon text, captions, and every
                              UI label in the app.

PROVENANCE, AND WHETHER THESE ARE MODIFIED VERSIONS
---------------------------------------------------

Both files were fetched from Google Fonts on 2026-08-30, from the woff2 URLs
that the Google Fonts CSS API returns for the latin unicode-range when asked
with a current desktop browser User-Agent:

  Bangers v25
  https://fonts.gstatic.com/s/bangers/v25/FeVQS0BTqb0h60ACH55Q2A.woff2

  Shantell Sans v13
  https://fonts.gstatic.com/s/shantellsans/v13/FeVvS0pCoLIo-lcdY7kjvNoQqWVWB0qWpl29ajppTuUTu_kJKmHesPOL-maYi4xZeHCNQ09eBlmv8ws8PQ.woff2

They are shipped byte for byte as Google served them. Nothing in this repo
subsets, re-compresses, renames or otherwise touches the binaries.

Even so, we take the conservative position: Google's latin file is itself a
subset of the upstream family, and OFL clause 3 counts a subset as a Modified
Version, so we treat what we ship as a Modified Version rather than argue that
serving someone else's subset makes it an Original Version.

That position costs us nothing here, because neither family declares a
Reserved Font Name. The upstream OFL.txt for each family carries a plain
copyright line with no "with Reserved Font Name" clause, so the only mention
of the phrase in either licence is the generic definition inside the licence
body. Clause 3 therefore imposes no renaming obligation on either family, and
we keep the original names, Bangers and Shantell Sans, in the CSS and in this
notice. Had either family reserved its name, we would have had to rename the
face we ship.

The two obligations that do bind us are met here: clause 2, the copyright
notice and licence travel with the files, which is this document; and clause
5, the fonts are distributed under the OFL and under no other licence, which
is why this file is separate from the licence covering Comic Crew itself.

Clause 1 is worth stating out loud too. Comic Crew is free and these fonts are
not sold by themselves, or at all.

The Bangers licence below was published with CRLF line endings upstream and
has been normalised to LF for this file. Not a character of its text changed.
