# Packing List

Smart packing checklists: start from trip presets (beach, camping, business,
with-kids, international, winter), add your own items, and check things off as
they hit the bag. "Uncheck all" resets the same list for the next trip. The
whole list travels inside a shareable link (checks reset for the recipient),
and everything persists in localStorage. A free tool by Sky Wolf Studios.

`CONFIG.tipUrl` in `app.js` for the tip jar. Test: `node test/helpers.test.mjs`.
