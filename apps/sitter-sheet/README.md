# Sitter Sheet

One clean printable page with everything the babysitter or pet sitter needs:
contacts, routines, meals, meds, allergies, house quirks, and a can't-miss
emergency line (911 + Poison Control on the babysitter version). Empty fields
stay off the printed page; columns auto-balance. Data lives in localStorage on
your device only — family details are nobody's business. A free tool by Sky
Wolf Studios.

Two modes (babysitter / pet sitter) with separate saved sheets. Print → "Save
as PDF" in any browser. `CONFIG.tipUrl` in `app.js` for the tip jar.
Test: `node test/smoke.test.mjs` (jsdom).
