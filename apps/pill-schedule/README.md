# Pill Schedule

A printable weekly medication card: every med with its dose, time of day, and
notes ("with food"), plus Mon-Sun check-off boxes. Tape it to the fridge or use
it on pill-organizer day. Built for the families juggling a parent's meds, the same audience as our Caregiver Log. A memory aid, never medical advice,
and it says so on the printout. localStorage only; health details are nobody's
business. A free tool by Sky Wolf Studio.

`CONFIG.tipUrl` in `app.js` for the tip jar. Test: `node test/smoke.test.mjs`.
